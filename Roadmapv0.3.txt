Work Breakdown Structure (WBS) - Phase 10: Creator Workflow
Objective: Transform Vibana from a standard storefront into a Multi-Role Platform where external designers can pitch artwork, and admins can approve and publish those designs.

Phase 10.1: Database Architecture & Roles 

a) Create the DesignSubmission database model to hold pending artwork.

b) Define the submission statuses (Pending, Approved, Rejected).

c) Configure Django User Groups to separate standard "Customers" from "Designers."

Phase 10.2: The Creator Portal (Frontend)

a) Build a secure dashboard exclusively for logged-in Designers.

b) Create the upload form for them to submit new artwork and descriptions.

c) Build a status-tracking grid so they can see if their work was approved or rejected.

Phase 10.3: The Admin Approval Pipeline

a) Create a custom queue in the Admin portal for you to review pending submissions.

b) Build the "Approve" logic: clicking a button automatically duplicates their submission data into a live Product on the storefront.

c) Wire up notification UI/messages for the designer.
